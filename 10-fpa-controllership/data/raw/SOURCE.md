# FP&A — raw / seed sources

## Primary (locked): Portfolio-seeded multi-entity P&L

No single public “budget vs actual” dataset matches Nordic Boardroom quality. Follow the bank pattern:

| Table (planned) | Role |
|-----------------|------|
| `FactPnL` | Period × entity × account × Actual / Budget amounts (local + reporting FX) |
| `DimEntity` | Subsidiaries (e.g. FI / SE / DK / NO style labels) |
| `DimAccount` | CoA map → Revenue / COGS / OPEX categories |
| `DimDate` | Continuous calendar |
| `FxRates` | Local → EUR reporting |

Generated by `scripts/seed-fpa-gold.mjs` into `../gold/`.
